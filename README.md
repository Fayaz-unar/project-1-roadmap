# 🗺️ AI Learning Roadmap Generator

An AI-powered web application built with **Streamlit** and **Python** that generates structured, personalized learning paths for any field or technology based on user skill level and available time.

🚀 **Live Demo:** [https://fayaz-roadmap-app.streamlit.app/](https://fayaz-roadmap-app.streamlit.app/)

---

## ✨ Features

* **Tailored Learning Paths:** Generates step-by-step roadmaps structured into progressive phases based on target skill and time availability.
* **Structured Output:** Automatically parses AI responses into clear sections covering Prerequisites, Core Topics, Hands-on Projects, and Learning Resources.
* **Streamlit UI:** Clean, responsive, and easy-to-use interactive web interface.
* **Robust Error Handling:** Features robust JSON parsing and string cleaning to prevent malformed API payload errors.

---

## 🛠️ Tech Stack

* **Frontend / Framework:** [Streamlit](https://streamlit.io/)
* **Language:** Python 3.10+
* **LLM Engine:** OpenAI Python SDK (Interfacing with Groq / OpenAI-compatible API)
* **Model:** `openai/gpt-oss-120b` (or `llama-3.1-8b-instant`)
* **Deployment:** Streamlit Community Cloud
